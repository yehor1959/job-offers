Happy path scenario:

As a user I want to go to web page and find job offers for Java developers. 

1. User go to the web page and register there;
2. User activate his account through e-mail;
3. User log to his account;
4. User sort that kind of offers which he needs;
5. User choose one of offers;
6. User read all info about an offer;
7. User apply to the offer;
